Half adder: adds two bits

Select A or B to switch it between 0 and 1.

Truth table

Select a row to set the inputs.

How it works

The sum bit is S = A ⊻ B. It is 1 when exactly one input is 1.

The carry bit is C = A ∧ B. It is 1 only when both inputs are 1, because 1 + 1 = 10 in binary.

It's called a half adder because it can't accept a carry from a previous column, so it can only add the rightmost bits of two numbers.

Full adder: adds two bits and a carry in

Select A, B or Cin to switch it. X, Y and Z label the outputs of the gates they are next to.

Truth table

Select a row to set the inputs.

How it works

A full adder is two half adders and an OR gate. The first half adder adds A and B, giving X = A ⊻ B and Z = A ∧ B.

The second half adder adds X to the carry in: S = X ⊻ Cin, with carry Y = X ∧ Cin.

If either half adder produces a carry, there is a carry out: Cout = Y ∨ Z.

Because it accepts a carry in, a full adder can add any column of a binary number.
